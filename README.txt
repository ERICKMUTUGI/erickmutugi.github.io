FREE DEPLOYMENT OPTION: GITHUB PAGES
1. Create/sign into a GitHub account.
2. Create a new repository, e.g. "true-sound-society".
3. Upload all four files.
4. Open Settings → Pages.
5. Select "Deploy from a branch", choose the main branch and /root.
6. Save.
7. GitHub will provide a free website address ending in github.io.

ALTERNATIVE: CLOUDFLARE PAGES
Upload/connect the project to Cloudflare Pages and use the free pages.dev address.

IMPORTANT:
The email address currently shown on the website is a placeholder:
info@truesoundsociety.org
Replace it with your real official TSS email before publishing.

The website is intentionally built as a static site, so there is no hosting/database cost for the basic version.
